# Datos

El análisis usa el conjunto de datos abiertos **Personas desaparecidas** del Ministerio del Interior de Ecuador:
https://www.datosabiertos.gob.ec/dataset/personas-desaparecidas

Descargue el archivo con los registros de 2017 a 2025 y guárdelo en esta carpeta como
`mdi_personasdesaparecidas_pm_2017_2025.xlsx`. El archivo no se incluye en el repositorio.
